# User Journeys

## Farmer lists birds
Register and complete seller profile; select category/product; enter quantity/unit, relevant age/weight, price/currency; specify location, availability and delivery/pick-up; review and publish; receive and respond to enquiries. A published listing is a seller-reported offer, not independent stock verification.

## Buyer discovers supply
Sign in and search; filter by product, location, quantity and relevant attributes; review listing and seller profile; contact seller or create a structured request.

## Buyer publishes a bulk request
An illustrative request might specify 2,000 broilers within a weight range, destination, delivery window and optional budget. The buyer enters product, quantity/unit, specification, destination, needed-by dates and terms, then publishes. Sellers respond with availability, quantity, price and conditions. The example is not a market-demand claim.

## Supplier lists inputs
Select feed, chicks, equipment or another supported category; provide pack size/unit, quantity, price and location; publish and maintain availability.

## Admin moderates a listing
Review a report, assess against published policy, record action and reason, notify the affected user and preserve an auditable record.

## Journey principles
Keep required fields proportional to the product, show clear units/examples, allow drafts, explain data visibility and support mobile and intermittent connectivity.
