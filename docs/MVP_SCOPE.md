# MVP 1 Scope

## Objective
Validate whether structured listings and buyer demand improve discovery and coordination in poultry markets.

## Included
| Capability | MVP outcome |
|---|---|
| Registration/authentication | Protected accounts |
| Profiles | Role-aware profiles |
| Catalogue | Controlled product taxonomy |
| Listings | Searchable supply offers |
| Search | Filtered listing discovery |
| Buyer requests | Structured demand records |
| Seller responses | Comparable offers |
| Messaging | Contextual communication |

## Excluded
Payments, escrow, checkout, logistics management, delivery tracking, disputes, ratings, advanced verification, price forecasting, AI recommendations and automated market reports.

## Pilot measures
Observe listing completion, listing freshness, search-to-contact rate, buyer request completion, seller response rate/time, trust concerns and next-step outcomes. Set numeric targets only after baseline observations.

## Release gates
Do not open broad public registration until identity, moderation, privacy, support and abuse-handling basics are ready. Do not describe offers as completed trades without an evidenced confirmation mechanism.
